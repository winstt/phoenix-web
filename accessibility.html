Accessibility Statement

Last updated: May 2026

The Phoenix Community Trust is committed to making its website accessible to everyone, regardless of disability or the technology used to access it. We believe that digital inclusion is inseparable from our broader mission of equity and justice.

Our commitment

We aim to conform to the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA as published by the World Wide Web Consortium (W3C). These guidelines explain how to make web content more accessible to people with disabilities.

Technical specification

This website relies on the following technologies for conformance with WCAG 2.2:

  • HTML5
  • CSS3
  • JavaScript (ECMAScript 2015+)
  • WAI-ARIA 1.2

What we have done

To make this website accessible, we have:

  • Provided a visible skip link to bypass navigation and reach main content directly
  • Used semantic HTML landmarks (main, nav, header, footer) throughout
  • Ensured all interactive elements are keyboard operable and have visible focus indicators
  • Provided ARIA labels, roles and states on all custom interactive components
  • Met or exceeded a 4.5:1 colour contrast ratio for all body text
  • Included text alternatives for all meaningful images
  • Implemented a logical heading hierarchy (h1 → h2 → h3)
  • Labelled all form fields explicitly with associated label elements
  • Ensured the site is navigable using keyboard alone (Tab, Enter, Space, Escape)
  • Respected the prefers-reduced-motion media query — animations are suppressed for users who have requested reduced motion in their operating system settings
  • Provided section-jump navigation for keyboard users

Known limitations

While we strive for full WCAG 2.2 AA compliance, the following known limitations exist at this time:

  • Some trustee profile images rely on object-fit cropping; if a photo has the subject off-centre, the visible portion may vary. We are reviewing photo composition.
  • The UK map region dots use hover interaction that may be less intuitive for touch-only devices; a screen-reader accessible list of regions is provided as a fallback.
  • News article pages currently use placeholder content; full article pages will be made accessible upon publication.

We are actively working to address these limitations and will update this statement as improvements are made.

Compatibility

This website is designed to be compatible with:

  • Recent versions of Chrome, Firefox, Safari and Edge
  • Screen readers including NVDA, JAWS and VoiceOver
  • Mobile browsers on iOS and Android
  • Keyboard-only navigation
  • Windows High Contrast Mode

How to get help or report an issue

If you experience any accessibility barriers on this website, or if you need information in an alternative format, please contact us:

  • Email: info@phoenix-trust.co.uk
  • Subject line: Accessibility

We will endeavour to respond within 5 working days and to resolve issues within 20 working days where technically feasible.

Enforcement

If you are not satisfied with our response, you can contact the Equality Advisory and Support Service (EASS):

  • Website: equalityadvisoryservice.com
  • Telephone: 0808 800 0082

Review

This statement was prepared in May 2026. We review and update it on an ongoing basis as we make improvements to the website.
